# EstudaFácil

## Sobre o projeto
O EstudaFácil é um site acadêmico desenvolvido apenas com HTML, sem CSS e sem JavaScript.

A proposta é oferecer um guia simples e útil para estudantes organizarem estudos, matérias, provas e materiais.

## Páginas
- Início
- Cronograma
- Dicas de estudo
- Materiais
- Planejamento

## Requisitos atendidos
- 5 páginas com menu de navegação
- Estrutura semântica com header, nav, main, section, article, aside e footer
- Tabela com colspan e rowspan
- Formulário com date, file, range, datalist, required e placeholder
- details e summary em mais de duas páginas
- figure e figcaption em duas páginas
- abbr, mark, del, ins, blockquote, cite, progress e meter
- arquivo de áudio local
- organização em pastas html/, img/, audio/ e video/
- data da prova em <time datetime="2026-09-25">25/09/2026</time>
- comentário HTML explicando uma dificuldade
- sem CSS
